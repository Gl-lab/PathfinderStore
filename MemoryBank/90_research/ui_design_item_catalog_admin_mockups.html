5 · Подтверждение необратимых действий

инлайн в ItemCatalogAdminView.vue · паттерн bf54312

Опубликовать ревизию №2?

Ревизия №2 станет публичной: её можно будет выставлять в магазинах и создавать конфигурации.

⚠ Текущая опубликованная ревизия №1 будет автоматически отозвана. Вернуть её в оборот будет нельзя. 1

Отозвать ревизию №1?

Предмет исчезнет из каталога для новых предложений магазинов.

⛔ Действие безвозвратно. Существующие конфигурации и уже выданные предметы не удаляются. 2
  • 1Формулировка про авто-отзыв обязательна — это скрытое последствие доменного правила «максимум одна опубликованная ревизия». Если опубликованной ревизии нет, показывается короткий вариант без блока.
  • 2Отзыв — терминальное состояние; текст явно отделяет каталог («новые предложения») от уже существующих предметов игроков.

  • 1Различаем причины: «нет кандидатов вообще» (пустой каталог/нет конфигураций — этот эскиз) и «кандидаты есть, но правило всё отфильтровало» (другой текст: «смягчите ограничения по уровню/редкости/бюджету»). Причину отдаёт reason-машина, как в emptyState.ts.
  • 2Тот же deep-link, что и в эскизе 6: /campaigns/42/item-catalog?action=configure&status=Published. Пул кандидатов генератора и список формы «Добавить из каталога» после согласования правил видимости — один и тот же набор.
  • 3«Подтвердить» неактивна с пояснением — по общему правилу «disabled + причина». Пустой прогон можно только отклонить.

Примечание: интерфейс пополнения ещё не реализован (Priority 16 поставил только backend: правила, прогоны с seed, превью/подтверждение через API). Эскиз фиксирует требование к его будущему пустому состоянию, чтобы связка «каталог → генерация» не потерялась при реализации restock-UI.

Соответствие плану: экраны 1–2 — read API и capabilities (§4–5 backend), диалог 3 — drafts/revisions (§3), диалог 4 — команда конфигурации (§2), блоки 6–7 — интеграция с Commerce, генерацией ассортимента и согласование правил видимости (§1). Рамки эскизов намеренно остаются светлыми в обеих темах страницы — приложение односхемное.
